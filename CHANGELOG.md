# Changelog

## 0.1.0

Initial release of AIVA HUD for Claude Code builds with TypeScript mods and native UI panes.

- Model and effort readings with native selectors.
- Context explorer with recorded turns, compactions, tool activity, and findings.
- Account usage windows, a five-hour pace forecast, and a seven-day daily budget.
- Live display previews, prompt hint controls, and keyboard shortcut configuration with backups and conflict checks.
- Prompt-cache countdown and optional experimental one-hour keep-warm, which makes additional model requests and consumes quota.
- A repository marketplace for installation through `/plugin install aiva-hud --marketplace vfesenko94/aiva-hud`.

Compatibility and retention limits are documented in [the guide](docs/guide.md). Interactive release checks are tracked separately in [the release checklist](docs/release-checklist.md).
